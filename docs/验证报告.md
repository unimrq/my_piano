# 网页版验证记录

日期：2026-10-29。本项目现在只维护网页版本，已移除 Electron 程序、桌面打包依赖及桌面专用检查。

## 本轮范围

- 保留 Web MIDI、IndexedDB 曲库、文件导入、浏览器全屏、谱面拖拽与循环、两种练习模式及记录。
- 浏览器检查使用标准 Playwright 缓存位置，可由 `PLAYWRIGHT_BROWSERS_PATH` 覆盖；截图及报告写入忽略 Git 的 `test-results/`。
- 增加本地运行、完整静态目录部署、Caddy HTTPS 及可选 GitHub Pages 说明。构建产物附带应用与第三方许可证。
- 公共源码只包含 5 首 CC0 双手谱。个人索引、流行曲原文件、旧截图、桌面测试数据与安装包不进入公开仓库。

## 自动检查

- 本机核心测试 58 项通过，覆盖单音、和弦、重复音、踏板、错漏音、速度、循环、导入及曲谱文件校验。
- 从待发布源码快照安装依赖成功，未使用 `--legacy-peer-deps`；TypeScript 与 Vite 生产构建通过。公开源码 56 项测试通过，2 项依赖私人曲谱的检查按预期跳过。
- Chromium / Windows WebKit 横竖屏检查通过：曲库、谱面完整高度与垂直居中、点击定位、导入、模拟 MIDI 跟弹 100%、单手跟弹软件 NoteOn 为零、IndexedDB 重载恢复。Chromium 另验证真实触摸事件拖选循环和断网重载。
- 两种浏览器在 1024×700、1024×768、768×1024、1194×834 四种尺寸下，完整标题、滑条、设置与练习按钮操作通过。
- 模拟 `/my_piano/` 静态子目录检查通过：5 首公共谱、鼠标图案、许可证、Service Worker 作用域及缓存后离线加载正常，无页面错误或资源加载失败。

浏览器报告及截图在 `test-results/`，不随公开源码提交。依赖安装和构建不需要 Electron。

浏览器检查使用模拟 MIDI；它可以验证网页接收、练习推进、发声指令及数据保存，不能证明实际钢琴或 iPad 兼容性。

## 已有曲谱核对

本机《刻在我心底的名字》MIDI 已逐小节对照 EveryonePiano 12352／NGERN 的 C 调简单版纸谱，32 小节共 339 个起音的音高、节奏及合并连音时值相符。自动转谱第 21 小节末拍的一组三连音已修正，源 MIDI 与练习音符未改动。结论只针对该简易编配，个人曲谱不随公共源码发布。
