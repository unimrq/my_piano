# 钢琴练习

中文网页钢琴练习工具。连接 USB MIDI 钢琴，跟着五线谱和下落音符练习。曲谱由服务端构建环境导入后随网页发布；收藏、设置与练习记录保存在当前浏览器，无账号或服务器数据库。

## 启动

需要 Node.js 22.12 或以上版本。

```sh
git clone https://github.com/unimrq/my_piano.git
cd my_piano
npm ci
npm run build
npm run web
```

在电脑 Chrome / Edge 打开 <http://localhost:4173/>。Windows 也可在安装依赖后双击 `启动网页版.cmd`。开发时运行 `npm run dev`，使用命令输出的地址。

远程和 iPad 使用请部署 HTTPS 静态站点，详见 [部署说明](docs/部署说明.md)。构建产物是完整的 `dist/`，不需要后端、数据库或常驻 Node.js。

## 连接与练习

1. 钢琴开机，用数据线连接当前浏览设备。FP-30X 使用琴背面的 **USB Computer**，USB-C 电脑或 iPad 可用 USB-C 转 USB-B 数据线。
2. 打开设备设置，点击“连接钢琴”并允许浏览器访问 MIDI，选择输入与输出。
3. 点击曲目卡片，顶栏选择“自由跟弹”，再点“开始”。初学建议双手或先分手：弹对当前音或和弦后立即进入下一组，不必追赶时钟。重复音须松开重弹，和弦目标键需同时按住，允许慢慢找键。
4. 熟悉后切换“节奏练习”，倒数一小节后按固定速度弹奏。顶栏滑条调速；重复工具可直接在谱面拖选起止小节，反复练习。

五线谱上下完整适配可用高度。整块谱面可拖拽，滚轮横向浏览，单击可定位开始线；练习区域高度和最少显示白键数可在设置中调整。支持平板横竖屏、触摸操作和浏览器全屏；浏览器未提供网页全屏接口时，使用浏览器自己的全屏菜单。

设置 → 显示 → 工具栏位置可选顶部或底部，默认顶部。底部布局将整条工具栏放到钢琴键盘下方，可避开部分浏览器全屏时的顶部触摸区域；选择保存在当前浏览器，所有曲目和模式共用。

手机竖屏中曲名保持单行，过长时省略；工具栏可左右滑动，播放和设置位于前端。手机横屏使用单行工具栏，并按可用高度缩放键盘；完整曲名仍保留在曲库和曲名提示中。

工具栏的模式选择器包含四种同级模式：

| 模式     | 行为                                       |
| -------- | ------------------------------------------ |
| 自由跟弹 | 等你弹对当前音或和弦后继续，不限时         |
| 自由练习 | 随意弹奏，显示上升音符，不计分             |
| 节奏练习 | 倒数后按固定速度运行，显示起音反馈         |
| 示范播放 | 自动演奏曲子，听完整双手与伴奏声部，不计分 |

工具栏按钮和空格控制当前模式的开始、暂停或继续，输入框、模式选择器和设置面板内不会触发空格快捷键。示范从当前定位开始，遵循所选小节区间；听整首时先点“重来”。切换模式会暂停并清理声音，模式和练习设置按曲目保存。

屏幕琴键支持点击和按住，自由跟弹也能用鼠标输入，无需先连接 MIDI；键盘可左右拖动，拖动后 8 秒内保留手动位置。所有模式默认最少显示 28 个白键，手动保存过的数量继续生效。进入曲目时，按整曲至少 97% 起音的最短音域一次确定白键数：设置数量够用就原样使用，不够才按主要跨度加两键留边，整首歌不再自动缩放。换手、模式、速度或循环保持键数；远音只在必要时平移，超宽和弦优先显示多数目标音，少量离群音不会被删除或静音。白键上下两行分别居中显示唱名和音名，C 音带八度数字（如 C3、C4），黑键不显示文字。“重来”取消片段循环和定位起点，回到第一小节。

示范播放随实际起音亮起对应琴键，松音或暂停后还原，不进入练习评分。琴键显示前沿厚度与黑键倒角；下落音条使用纵向渐变，触键时沿键面亮起短光线，接触期间持续迸发彩色碎片和光点，松音后自然消散。音符主色仍区分左右手。

自由跟弹不自动播放其他声部，即使旧设置曾开启伴奏也一样。自己的琴声由钢琴发出，网页不重复回放输入。示范和手动开启的节奏伴奏优先通过所选 MIDI 输出到钢琴；未选择钢琴输出时用电脑扬声器，也可在设备设置的输出中明确选择“电脑扬声器”。本地打包的钢琴采样可离线使用，不加载远程音源。节拍器由当前设备发声。断线或切到后台会暂停，返回后由用户继续。

节奏练习默认以起音前后 150 毫秒判定，谱面标记正确、错音、漏音与早晚偏差。按键时值不足只提示，不扣起音分；力度和踏板不评分。结束后可查看问题小节与记录。每日视奏提供三档离线生成的原创练习。

## 曲库与服务端导入

默认曲库共 9 首，克隆源码或构建 Docker 镜像均会收录：

- 5 首 Noctave CC0 入门双手谱：《欢乐颂》《小星星》《摇篮曲》《月光下》《雅克兄弟（两只老虎旋律）》，保留来源 MusicXML 原文件，来源及 SHA-256 见 [公共曲库索引](public/catalogue/manifest.json)。
- 4 首已有双手 MIDI：《月亮代表我的心》《刻在我心底的名字（C调简单版）》《晴天》《青花瓷》，原文件未改写，来源及 SHA-256 见 [流行曲索引](src/personal-catalogue.json)。前两首标初级，后两首保留完整编配并标中级。

网页不提供上传、文件选择、拖放或 ZIP 导入入口，也没有公开 HTTP 上传接口。维护者或后台 AI 在源码目录使用 Node.js 工具处理本地 `.mid`、`.midi`、`.xml`、`.musicxml`、`.mxl` 和 `.zip`，核对摘要后写入曲库，再构建部署：

```sh
node scripts/import-scores.cjs "/path/to/练习合集.zip"
node scripts/import-scores.cjs "/path/to/练习合集.zip" --write
npm run build
docker compose up -d --build
```

第一条默认只预览，不写文件。输入要求、ZIP 限额、来源标注与回滚步骤见 [服务端导入说明](docs/服务端导入.md)。生产 Nginx 容器只提供静态文件，导入工具在源码或构建环境运行。优先使用 MusicXML/MXL 保留原谱信息；声部分配可在曲目设置中调整，指法在进入单曲后生成。

曲库首页只读取列表信息，选中一首时才下载、解析和生成这首曲谱。已打开曲目的谱面、指法和声部分配会保存在本机，返回或刷新后直接复用；文件 SHA 或解析版本变化时，仅在再次选中该曲时重建。未打开曲目不预取、不提前计算，小节数和时长在打开后显示。

MIDI 显示为“自动转谱”：按十六分音符量化，保留完整八分三连音，练习使用原始演奏时间，不保证还原出版谱或自动推断可靠指法。复杂总谱建议先提取钢琴声部。反复、房子、D.C./D.S./Coda 保留显示，判定按书写顺序进行，不自动展开；需要反复可用 A/B 循环。装饰音仅显示，移调声部请先导出实音谱。不支持 PDF、图片或音频转谱。

两份曲库索引独立保留，既有曲目 ID 不变。流行曲的原曲及编配权利归原权利人，不适用应用的 MIT 或公共谱的 CC0 许可，逐曲来源见 [来源说明](NOTICE.md)。此前保存在浏览器的曲谱和记录继续保留；服务端新导入的曲谱随下一次静态构建或 Docker 镜像发布。

## 浏览器与本地数据

Web MIDI 需要受支持的浏览器，以及 HTTPS 或本机 localhost 安全上下文；普通局域网 HTTP 不能保证连接 MIDI。[MDN 接口说明](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/requestMIDIAccess)

iPad Safari 当前不提供原生 Web MIDI。iPad 可用 MIDIWeb Browser 的 MIDI 桥接尝试连接，仍需实际设备验证 MIDI、节拍器、全屏与休眠恢复；平板视口自动测试不等于 iPad 真机测试。[浏览器兼容数据](https://github.com/mdn/browser-compat-data/blob/main/api/Navigator.json)

曲库使用状态、设置和最近 1000 次记录保存在浏览器 IndexedDB，不跨设备同步。同一设备更换浏览器、域名、协议或端口会使用独立数据；清除站点数据可能删除记录。当前没有完整数据导出入口，请保留源曲谱，并避免清除使用中的站点数据。旧曲库迁移前会在 IndexedDB 保留 `before-scores` 备份。

“练习记录”新增今日／累计练琴时长，以及每次实际弹奏的曲目、模式、开始和结束时间。从本次更新后开始记录，不用既有评分时长倒推。MIDI 和屏幕琴键都计入；仅记录已开始的跟弹／节奏练习，以及未暂停的自由练习。示范播放、曲库停留、后台和暂停不计。30 秒无输入会分段，松键后的尾部空闲不计入；短暂休息保留在同一段，卡键最多连续计 30 秒。跨午夜按当地日期拆分统计。

练琴时段同样仅存当前浏览器，单独写入 IndexedDB，不上传服务器。进行中的时段每 5 秒保存快照，暂停、完成或离开时收尾；意外关闭时可能损失最后一次快照后的几秒。练习成绩保留在记录页的折叠区。

HTTPS / localhost 首次缓存页面和音源后可离线重载，已打开的曲谱可离线继续练习；未打开的曲目首次需要连接服务器。离线缓存和个人曲库是两套存储，部署更新不需要清空个人数据。更新步骤见 [部署说明](docs/部署说明.md#更新与离线缓存)。

## 自动指法

进入缺少指法的曲目时，网页会在开启指法显示的情况下补全缺失建议；也可在练习设置 → 自动指法中选择手掌大小，点击“生成缺失指法”。生成在浏览器后台完成，结果写入五线谱并保存在当前浏览器，离线缓存完成后也可生成，无需服务器计算。已有指法保留，伴奏和忽略声部不参与。先确认左右手声部分配；修改声部后已有标注不会自动重新规划。

数字 1～5 分别代表拇指至小指。建议算法改编自 PianoPlayer，按手部移动成本搜索，不保证等同教师或出版谱指法。超出五指、跨度或与原标注冲突而无法分配的音组保留空白，不强行标注。当前最多处理两万音；不自动处理交叉手或识别实际使用的手指。当前入口是“补全缺失”，再次点击会保留上一次生成的结果。

和弦在谱面只显示一个指法：右手取有标注的最高音，左手取有标注的最低音，减少数字堆叠。完整建议仍保留在曲谱数据中。

设置 → 显示 →“显示指法”可隐藏或恢复谱面上的指法数字，默认开启，偏好跨曲目及刷新保存。关闭只影响显示，原谱与已生成的指法仍保留。

Docker 可在项目目录运行 `docker compose up -d --build`，默认打开 `http://localhost:8080/`，可看到上述 9 首曲目；更新源码后再次运行同一命令重建即可。远程访问使用 HTTPS 反向代理。镜像构建包含核心测试，GitHub Actions 另检查容器启动、资源完整性与运行权限。配置细节见[部署说明](docs/部署说明.md#docker-部署)，对应提交的运行结果见 [Docker 检查](https://github.com/unimrq/my_piano/actions/workflows/docker.yml)。

## 自由练习

打开一首曲目，在工具栏选择“自由练习”，与其他三种模式并列。保留当前曲名、五线谱和定位线，可拖拽浏览或单击谱面定位；下方显示自己弹出的上升音符，不自动推进曲谱。

连接 MIDI 后进入此模式即可弹奏。按住时音条增长，松开后继续上移，支持和弦和重复音；不计分、不自动播放原曲或伴奏。工具栏可清空音条。此模式按曲目保存，切回自由跟弹可继续常规练习，其他歌曲的模式不变。切后台、断线或退出时释放界面按键状态，画面历史有上限；显示设置中的白键数与音区选择继续适用。

自由练习的“暂停 / 继续”和空格控制音条，暂停时停止接收新音符，继续后从原位置上移。也可点击屏幕琴键生成音条。需要听原曲时，将工具栏模式切为“示范播放”。
